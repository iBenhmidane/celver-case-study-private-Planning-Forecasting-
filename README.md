# Retail Sales Analysis Case Study

Take-home Excel case study completed during a Hamburg consulting interview process (April 2026). Private archive.

## What's in the file

Excel workbook with 11 tabs:
- **Raw data**: fact_sales (~79k rows), dim_customer, dim_products
- **Cleaned data**: fact_sales_clean, dim_customer_clean, dim_product_clean
- **Analysis**: Executive_Summary, Pivot_monthly_report, Pivot_seasonality
- **Planning**: Planning_2023 (mock-up)
- **Documentation**: assumption_log

## Skills demonstrated

- Star schema data modeling (fact + dimension tables)
- Data cleaning and reconciliation (with audit trail)
- Executive reporting (KPIs, YoY analysis, country share)
- Pivot tables and seasonality analysis
- Forward-looking planning with assumption log
- Bilingual deliverable (German findings, English structure)

## Scope

- 7 countries (DE, FR, IT, ES, CH, UK, US)
- 2020 to 2022 actuals, 2023 plan mock-up
- ~79k transactions cleaned and modeled
